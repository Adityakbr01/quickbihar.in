## Problem
The `Shell` component in `prerender.tsx` renders an identical "Trending Stores, Categories & Delivery Locations" section with the same 40 links on EVERY prerendered page. This creates:
- Duplicate internal link patterns across all pages (wastes crawl budget)
- Irrelevant links (e.g., jewellery products linked from clothing category pages)
- Diluted topical relevance signals
- No page-contextual navigation for users/crawlers

## Supporting Evidence
- **Source:** `user-web/src/seo/prerender.tsx` lines 186-290 — Shell component uses fixed link arrays
- **Source:** Live homepage HTML — 40 links including products, categories, malls, locations
- **Source:** Live `/jewelery/` HTML — IDENTICAL 40 links (clothing products, not jewellery)
- **Source:** Live `/locations/bihar/buxar` HTML — IDENTICAL 40 links
- **Retrieval timestamp:** 2026-10-19

## Proposed Change
Modify `Shell` component to accept page-contextual link sets:
1. Add `contextualLinks` prop to Shell component
2. In `prerender()` entry, compute relevant links per route type:
   - Home: Top products + key categories + locations (current behavior OK)
   - Category pages: Sibling categories + top products IN that category + sub-locations
   - Product pages: Related products (same category/vertical) + category parent
   - Jewellery pages: Jewellery products + collections + jewellery FAQs
   - Location pages: Local products + sub-locations + local categories
   - Mall pages: Mall products + other malls
3. Limit to 20-30 most relevant links per page

## SEO/User Rationale
- Concentrates internal link equity on topically relevant pages
- Improves crawl efficiency (crawler follows relevant links)
- Better user experience (contextual navigation)
- Stronger topical authority signals per page template

## Expected Benefit
- Improved internal link graph relevance
- Better distribution of link equity to important pages
- Reduced crawl waste on irrelevant links
- Potential improvement in category/product page rankings

## Risk Assessment

- **Affected scope**: All 93 prerendered pages' shell HTML
- **Dependencies**: Requires route-type detection in prerender entry
- **Regression**: Could reduce cross-vertical discovery if over-filtered
