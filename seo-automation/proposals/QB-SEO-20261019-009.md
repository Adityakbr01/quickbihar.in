## Problem
No authorized API access to Google Search Console or GA4 Data API. All search performance, indexation, and traffic metrics are unavailable for automated daily reporting. Current baseline relies on historical manual exports (Oct 14) which are stale.

## Supporting Evidence
- **Source:** `seo-automation/config/seo-policy.yaml` — integrations enabled but `credentials_source: "secret_manager_or_environment"` not configured
- **Source:** Historical 2026-10-16 report — "Direct GSC API: Not connected", "Direct GA4 Data API: Not connected"
- **Source:** No service account JSON or OAuth tokens in repository (correctly)
- **Retrieval timestamp:** 2026-10-19

## Proposed Change
1. Create Google Cloud service account for GSC API (Search Console API)
2. Grant service account "Owner" or "Full" permission on GSC property (https://quickbihar.in)
3. Create service account for GA4 Data API (or use same)
4. Grant "Viewer" role on GA4 property
5. Store service account JSON securely (GitHub Actions secrets, NOT in repo)
6. Update automation to use credentials for API calls
7. Test API access: fetch search performance, index coverage, GA4 organic traffic

## SEO/User Rationale
Without API access, SEO automation cannot:
- Measure search performance trends
- Track indexation changes
- Correlate technical changes with organic traffic
- Generate evidence-based daily reports
- Alert on regressions

## Expected Benefit
- Automated daily GSC/GA4 data in reports
- Evidence-based prioritization
- Regression detection
- Historical comparison across equivalent periods
