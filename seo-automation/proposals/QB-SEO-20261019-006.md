## Problem
The prerender shell (`#qb-seo-shell`) is wrapped in `style={{display:'none'}}` with `aria-hidden="true"`. The only visible element before React hydration is `#qb-boot` (spinner). Google's Web Rendering Service (WRS) renders the page and sees only the spinner — all indexable content (H1, description, links, schema) is hidden by inline CSS. This directly contributes to historical "Crawled - currently not indexed: 10" URLs.

## Proposed Change
Replace hidden shell with visible lightweight server-rendered preview:
1. Remove `display:none` and `aria-hidden="true"` from shell
2. Style shell as clean, lightweight HTML preview (minimal CSS, no animations)
3. Keep `#qb-boot` spinner as overlay that fades out on React hydration
4. Ensure shell content is semantically correct (H1, meta description, contextual links, breadcrumbs)
5. Test that React hydration replaces shell cleanly without layout shift

Per Phase 2 plan (Days 4-7): "Replace `display:none` with a clean, lightweight server-rendered HTML preview styled with lightweight CSS so content is visible to users and WRS alike prior to client hydration, eliminating hidden text classification."

## SEO/User Rationale
- Makes prerendered content visible to WRS (fixes "Crawled - currently not indexed")
- Provides meaningful content for users with slow JS or no-JS
- Improves FCP/LCP (content visible before hydration)
- Maintains SPA experience after hydration

## Expected Benefit
- Reduction in "Crawled - currently not indexed" URLs

- Accessible fallback for no-JS users
