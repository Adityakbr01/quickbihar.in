## Problem
Historical issue: Prerender shell linked jewellery products using `/product/:slug` format, but the canonical URL for jewellery products is `/jewelery/product/:slug`. The `/product/:slug` version for jewellery items returns `robots: noindex, nofollow` and canonicalizes to the jewellery URL. This created:
- Wasted crawl budget on noindex pages
- "Excluded by 'noindex' tag" in GSC
- "Duplicate without user-selected canonical" in GSC

Code fixes exist in `prerender.tsx` (lines 370, 439, 494) using ternary: `jewel ? /jewelery/product/:slug : /product/:slug`. Need to verify LIVE output matches the fix.
