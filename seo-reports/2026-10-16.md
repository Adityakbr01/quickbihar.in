## 4. Findings & Verified Root Causes

### [P1 Resolved] Internal Linking to Non-Canonical `/clothing/home`
- **Evidence:** `user-web/src/seo/prerender.tsx` line 215 rendered `<a href="/clothing/home">Home</a>` across all 96 prerendered routes in the site's primary HTML shell.
- **Impact:** Forced search crawlers on every page to discover and crawl `/clothing/home` rather than apex `/`. Led directly to GSC *Duplicate without user-selected canonical* (4 pages) and split domain authority.
- **Fix Applied:** Changed `<a href="/clothing/home">Home</a>` to `<a href="/">Home</a>` in `user-web/src/seo/prerender.tsx`.

### [P1 Resolved] Static & Location Shells Emitting Non-Canonical Jewellery Product URLs
- **Evidence:** `user-web/src/seo/prerender.tsx` (lines 370 & 612) mapped all products to `/product/:slug` without distinguishing jewellery items. When crawled, `/product/:jewellery-slug` returns `robots: noindex, nofollow` and canonicalizes to `/jewelery/product/:slug`.
- **Impact:** Wasted crawl budget, triggering *Excluded by 'noindex' tag* and *Duplicate without user-selected canonical*.
- **Fix Applied:** Added vertical discrimination in `prerender.tsx` (`jewel ? /jewelery/product/:slug : /product/:slug`) for static hub pages and Buxar location pages.

### [P2 Resolved] Broken Mall Breadcrumb Target
- **Evidence:** `user-web/src/seo/prerender.tsx` (line 440) and `user-web/src/seo/SeoRouter.tsx` (line 181) linked Malls breadcrumbs to `/clothing/home` instead of `/malls`.
- **Impact:** Faulty BreadcrumbList JSON-LD schema and broken hierarchy.
- **Fix Applied:** Updated breadcrumb target to `/malls`.

### [P1 Open Proposal] Prerender Shell Visibility (`display:none` vs WRS)
- **Evidence:** `user-web/src/seo/prerender.tsx` wraps the crawlable HTML shell in `<div id="qb-seo-shell" style={{ display: 'none' }} aria-hidden="true">` with `<p style={{ display: 'none' }}>`.
- **Observation:** Verified live via production crawl (`https://quickbihar.in/category/sarees`). When Googlebot's Web Rendering Service (WRS) renders the page, all indexable body text is hidden by inline CSS, showing only the `#qb-boot` spinner. This directly contributes to 10 URLs in *Crawled - currently not indexed*.
- **Proposal for Days 4–7:** Replace `display:none` with a clean, lightweight server-rendered HTML preview styled with lightweight CSS so content is visible to users and WRS alike prior to client hydration, eliminating hidden text classification.
